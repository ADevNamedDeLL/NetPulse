# NetPulse Website

A standalone landing page for [NetPulse](https://github.com/ADevNamedDeLL/NetPulse), a lightweight Windows system tray network speed monitor.

## Files

- `index.html` — main landing page
- `style.css` — layout, responsive design, animations and visual styling
- `script.js` — lightweight interface interactions and demo speed values
- `favicon.svg` — NetPulse browser icon

## Deployment

The website is static and can be deployed directly to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any standard web server.

No build process or package installation is required.

## Notes

The speed values displayed in the landing page are visual demo values. The website does not read the visitor's network connection or communicate with the NetPulse application.
